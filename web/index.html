Financial Fraud Detection

Machine Learning Based Fraud Risk Assessment

Score a single transaction with the frozen production pipeline. Logistic Regression with class weighting, sigmoid calibration, and a review threshold loaded from model metadata. This is an internship prototype, not a certified banking system.

Risk score is a model-generated indicator and is not proof of fraud. A flagged result means the transaction should be reviewed by a person.
Model Logistic Regression + Class Weight
Calibration Sigmoid
Threshold 10%
Recall 76.04%
Precision 23.78%
ROC-AUC 76.46%
